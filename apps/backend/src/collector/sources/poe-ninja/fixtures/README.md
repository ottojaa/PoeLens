# poe.ninja fixtures

Recorded by hand on 23 Nov 2026 with the PoeLens User-Agent, then trimmed to a handful of lines each. Tests never call the live API.

- `leagues.json`: the PoE 2 leagues endpoint, as recorded.
- `leagues-new-first-league.json`: **hand-made**, not recorded. `leagues.json` with a new challenge league and its hardcore version put first, the way poe.ninja lists a league on launch day.
- `exchange-currency.json`: the `Currency` exchange overview for Forbidden Rites. Includes the three currencies themselves, a thinly traded line (Chance Shard), and expensive rarely-traded ones (Mirror of Kalandra).
- `stash-unique-weapons.json`: the `UniqueWeapons` stash overview for Forbidden Rites, mods stripped. Winter's Bite has a single listing at 39,235,000 divine.
