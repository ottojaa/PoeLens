# PoeLens

A self-hosted companion app for Path of Exile 2 (and later Path of Exile 1). It records economy prices over time, lets you watch the items you care about, and answers price questions over MCP.

**Status:** being set up for the Path of Exile 2 1.0 launch on 11 December 2026. Nothing runs yet.

Planned for the first version: hourly price history from [poe.ninja](https://poe.ninja), an economy view you can configure, search across everything, per-item history charts, a watchlist, and an MCP server. It ships as a web app and an Electron desktop app, with invite-only accounts.
